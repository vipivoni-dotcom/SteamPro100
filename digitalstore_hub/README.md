# DigitalStore Hub — версия 0.2

Локальная система учёта для продажи **собственных** цифровых продуктов:
каталог с юридическим фильтром НПД (422-ФЗ), реестр поставщиков, учёт
документов, продажи, финансовая аналитика и административная панель.
К маркетплейсам пока не подключена.

> Фильтр и расчёт налога — техническая защита и оценка, а не юридическая или
> налоговая консультация. Спорные случаи проверяйте по FAQ ФНС / с юристом.

## Запуск

```bash
cd digitalstore_hub
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
uvicorn app:app --reload
```

- Админ-панель: http://127.0.0.1:8000/admin
- Swagger API: http://127.0.0.1:8000/docs

База из версии 0.1 подходит — новые таблицы создаются автоматически.

| Переменная           | По умолчанию      | Значение                                         |
| -------------------- | ----------------- | ------------------------------------------------ |
| `DSH_TAX_REGIME`     | `npd`             | `npd`, `ip` или `ooo`                            |
| `DSH_DB_PATH`        | `digitalstore.db` | путь к файлу SQLite                              |
| `DSH_UPLOADS_DIR`    | `uploads`         | папка для файлов документов                      |
| `DSH_ADMIN_PASSWORD` | не задан          | если задан — вход по логину `admin` и паролю      |

Без `DSH_ADMIN_PASSWORD` панель открыта всем, кто может достучаться до порта.
Не запускайте с `--host 0.0.0.0` без пароля.

## Админ-панель

| Вкладка             | Что можно сделать                                                                 |
| ------------------- | --------------------------------------------------------------------------------- |
| Обзор               | Сводка: товары, поставщики, выручка, чистая прибыль, лимит НПД, истекающие документы |
| Товары              | Добавление с юридической проверкой, категории, статусы (черновик/активен/архив), цена |
| Поставщики          | Карточка проверки, 100-балльная оценка, переоценка галочками прямо в реестре       |
| Документы           | Договоры, происхождение, право перепродажи, акты, лицензии, авторство; файлы; сроки |
| Продажи и аналитика | Регистрация продаж, номер чека «Мой налог», возвраты, разрезы по месяцам/товарам/каналам |

## Товарные линии

- **Линия A** — `ownership: own_created` и типы `ebook`, `template`,
  `spreadsheet`, `course`, `software`. Допускается на НПД.
- **Линия B** — `resale` / `agency` либо типы `game_key`, `license_key`,
  `subscription`, `gift_card` (даже если помечены как собственные).
  На НПД — всегда HTTP 422. На ИП/ООО — только с поставщиком `candidate`.

## Поставщики

Баллы: происхождение 20, право перепродажи 25, документы 15, API 15,
работоспособность 10, возвраты 10, территория 5.
90–100 → `candidate`; 75–89 → `request_documents`; < 75 → `rejected`;
нет права перепродажи или подтверждения происхождения → `rejected` независимо от баллов.

## Документы

Привязываются к поставщику или товару. Статус по сроку: `valid`,
`expiring` (≤ 30 дней), `expired`, `no_expiry`. Файлы: PDF, DOCX, XLSX,
JPG, PNG, TXT до 10 МБ; на диске хранятся под служебным именем.

## Финансы

- Налог НПД (оценка): 4 % с продаж физлицам, 6 % — юрлицам/ИП, от полной
  суммы продажи; вычет 10 000 ₽ не учитывается.
- Чистыми = выручка − комиссия площадки − налог.
- Возвраты исключаются из выручки (не забудьте аннулировать чек).
- Лимит НПД 2 400 000 ₽/год, предупреждение с 80 %.
- Продажи без номера чека подсвечиваются.

## API

`GET /` · `GET /dashboard` · `POST/GET /categories` · `POST /legal/check` ·
`POST/GET /products` · `GET/PATCH/DELETE /products/{id}` ·
`POST/GET /suppliers` · `GET /suppliers/criteria` · `GET /suppliers/{id}` · `PUT /suppliers/{id}/checks` ·
`POST/GET /documents` · `GET/DELETE /documents/{id}` · `POST/GET /documents/{id}/file` ·
`POST/GET /sales` · `PATCH /sales/{id}` · `GET /analytics/summary?year=`

Товар с продажами или документами не удаляется (409) — переведите его в архив.
